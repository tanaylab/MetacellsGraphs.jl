# MetacellsGraphs.jl

Draw the figures worth looking at of a metacells repository.

This sits between [SomeGraphs.jl](https://github.com/tanaylab/SomeGraphs.jl), which draws from arrays and knows nothing
of metacells, and [Metacells.jl](https://github.com/tanaylab/Metacells.jl), which computes and draws nothing.

See the [documentation](https://tanaylab.github.io/MetacellsGraphs.jl/v0.1.0/index.html).
