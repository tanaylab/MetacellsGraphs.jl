MetacellsGraphs.ScatterGraphs — Module

Scatter graphs of a metacells repository.

MetacellsGraphs.ScatterGraphs.metacells_gene_gene_graph — Function 
metacells_gene_gene_graph(
    daf::DafReader;
    x_gene::AbstractString,
    y_gene::AbstractString,
    gene_fraction_regularization::Real = ```1.0e-5```,
)::PointsGraph

The expression of one gene against another, a point per metacell, on log scale.

If the metacells have a type, the points are colored by it, using the colors of the type axis, and the types are shown in a legend. If they do not, they are all the same color; nothing else about the graph changes.

Inputs

Axes

gene (required): Sequenced genes.

metacell (required): Minimal-sized groups of cells for robust point estimates.

type (optional): Distinct named biological cell states.

Vectors

metacell @ type ::AbstractString (optional): The type each metacell belongs to.

type @ color ::AbstractString (optional): A unique color for each type for visualizations.

Matrices

gene, metacell @ linear_fraction ::Union{Float32, Float64} (required): The linear fraction of the UMIs of each non-excluded gene in each metacell, out of the total UMIs.

MetacellsGraphs.ScatterGraphs.blocks_gene_gene_graph — Function 
blocks_gene_gene_graph(
    daf::DafReader;
    x_gene::AbstractString,
    y_gene::AbstractString,
    gene_fraction_regularization::Real = ```1.0e-5```,
)::PointsGraph

The expression of one gene against another, a point per block, on log scale.

This is metacells_gene_gene_graph of the blocks the metacells were grouped into, and reads the same way; a block is coarser, so the same pair of genes shows fewer points and less scatter.

Inputs

Axes

gene (required): Sequenced genes.

block (required): Distinct groups of metacells with "very close" cell state.

type (optional): Distinct named biological cell states.

Vectors

block @ type ::AbstractString (optional): The type each block belongs to.

type @ color ::AbstractString (optional): A unique color for each type for visualizations.

Matrices

gene, block @ linear_fraction ::Union{Float32, Float64} (required): The linear fraction of the UMIs of each non-excluded gene out of the total UMIs in each block.

MetacellsGraphs.ScatterGraphs.metacells_umap_graph — Function 
metacells_umap_graph(daf::DafReader)::PointsGraph

The 2D UMAP embedding of the metacells, a point per metacell.

If the metacells have a type, the points are colored by it, using the colors of the type axis, and the types are shown in a legend. If they do not, they are all the same color; nothing else about the graph changes.

The coordinates are the arbitrary output of the UMAP projection, so the axes are drawn without ticks or a grid; only which points are near which other points means anything.

Inputs

Axes

metacell (required): Minimal-sized groups of cells for robust point estimates.

type (optional): Distinct named biological cell states.

Vectors

metacell @ umap_x ::Union{Float32, Float64} (required): The X coordinate of each metacell in a 2D UMAP projection.

metacell @ umap_y ::Union{Float32, Float64} (required): The Y coordinate of each metacell in a 2D UMAP projection.

metacell @ type ::AbstractString (optional): The type each metacell belongs to.

type @ color ::AbstractString (optional): A unique color for each type for visualizations.

MetacellsGraphs.ScatterGraphs.blocks_umap_graph — Function 
blocks_umap_graph(daf::DafReader)::PointsGraph

The 2D UMAP embedding of the blocks, a point per block.

This is metacells_umap_graph of the blocks the metacells were grouped into, and reads the same way; a block is placed at the mean position of its metacells, so the same embedding shows fewer points closer to its center.

Inputs

Axes

block (required): Distinct groups of metacells with "very close" cell state.

type (optional): Distinct named biological cell states.

Vectors

block @ umap_x ::Union{Float32, Float64} (required): The X coordinate of each block in a 2D UMAP projection.

block @ umap_y ::Union{Float32, Float64} (required): The Y coordinate of each block in a 2D UMAP projection.

block @ type ::AbstractString (optional): The type each block belongs to.

type @ color ::AbstractString (optional): A unique color for each type for visualizations.

MetacellsGraphs.ScatterGraphs.GENE_FRACTION_REGULARIZATION_FOR_GRAPHS — Constant

The regularization added to a fraction before taking its log, so that a gene seen in no cell of an entity has a value to be drawn at instead of falling off the bottom of the axis. It is deliberately small: a fraction this size is one UMI in a hundred thousand, which is below anything these graphs are read for.
